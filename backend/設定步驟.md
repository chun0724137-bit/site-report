# 松青現場回報 — Google 後台設定步驟

共三個檔案:
- `松青現場回報_後台範本.xlsx`:後台試算表範本(已含 4 個工程的契約項目、工人名單、機具、土質、出土去處)
- `Code.gs`:後台程式
- `index.html`:現場與老闆使用的頁面

## 一、建立試算表(約 3 分鐘)
1. 用公司的 Google 帳號開啟 Google 雲端硬碟,把 `松青現場回報_後台範本.xlsx` 上傳。
2. 對檔案按右鍵 >「選擇開啟工具」>「Google 試算表」,再按「檔案」>「儲存為 Google 試算表」。之後都用這份 Google 試算表,原本的 xlsx 可以刪掉。
3. 切到「設定」分頁,把第 2、3 列的「通行碼」和「管理者通行碼」改成您自己訂的兩組(不要相同)。
   - 現場同仁用「通行碼」:可以回報、可以改 3 天內的回報。
   - 您和老闆用「管理者通行碼」:另外可以改任何日期、刪除回報、改名單、管理工程。
4. 每個工程有自己的契約分頁,名稱是「契約-」加上工程簡稱(例如 `契約-三峽北大`)。檢查「項次」欄:1.10 這種項次必須顯示成 `1.10`,不能變成 `1.1`。之後自己新增項目前,先把那一格的格式設成「純文字」再輸入。

## 二、貼上後台程式並部署(約 5 分鐘)
1. 在試算表按「擴充功能」>「Apps Script」。
2. 把編輯器裡原本的內容全部刪掉,貼上 `Code.gs` 的全部內容,按儲存。
3. 上方函式選單選 `setup`,按「執行」。第一次會要求授權,選公司帳號 >「進階」>「前往(不安全)」>「允許」。這一步會補齊分頁並把項次欄設成純文字。
4. 右上角「部署」>「新增部署作業」> 類型選「網頁應用程式」:
   - 執行身分:**我**
   - 誰可以存取:**所有人**
5. 按「部署」,複製出現的「網頁應用程式網址」(結尾是 `/exec`)。
6. 用瀏覽器開啟那個網址,看到 `{"ok":true,"hello":"松青現場回報後台運作中"}` 就代表成功。

之後如果換了新版 `Code.gs`,要到「部署」>「管理部署作業」> 編輯 > 版本選「新版本」> 部署,網址不會變。

### 更新成「日誌分頁＋結算資料」這一版(2026-11 起)
1. 「擴充功能」>「Apps Script」,把內容全部換成新的 `Code.gs`,按儲存。
2. 上方函式選單選 `setup`,按「執行」。這版多了「產生 Excel 檔」的功能,**會再要求一次授權**,照第二步第 3 點按「允許」。
   - 會自動在「工程」「派工地點」「施工項目」分頁最右邊補上新欄位,並新增「派工數量」「照片」兩張分頁。
   - 會產生每個工程的「日誌_簡稱」分頁。舊的「附件-簡稱」分頁不會再更新,確認日誌沒問題後可以自己刪掉。
3. 「部署」>「管理部署作業」> 鉛筆圖示(編輯)> 版本選「新版本」>「部署」。**不要按「新增部署作業」**,網址會變。
4. 重新整理試算表,上方選單會多一個「現場回報」,裡面有「重新整理日誌」和「產生結算資料…」。

## 三、頁面
- 把第二步的網址交給 Claude,填進 `index.html` 後放上 GitHub Pages,現場用那個網址開啟即可。
- 還沒放上 GitHub 之前也可以先試:直接用瀏覽器開 `index.html`,第一次會問「後台網址」和「通行碼」,填入即可。
- iPhone:用 Safari 開啟 > 分享 >「加入主畫面」。
- 老闆版:網址最後加 `#boss`;人員出工 `#people`;施工進度 `#progress`。

## 四、日常維護(都在試算表上做)
| 要做的事 | 在哪裡改 |
|---|---|
| 新工程 | APP 設定頁「新增工程」,會自動多一個「契約-簡稱」的空白分頁;把詳細價目表的項次、項目、單位、單價、數量貼進去。若手動加,分頁名稱必須是「契約-」加上「工程」分頁裡的簡稱 |
| 改工程簡稱 | 「工程」分頁的簡稱和契約分頁的名稱要一起改,兩邊要一致 |
| 工程完工 | APP 設定頁把狀態改「完工」,或「工程」分頁改狀態。不要刪列 |
| 契約變更 | 該工程的「契約-簡稱」分頁:在「第一次變更數量」填變更後數量;新增項目加一列(原契約數量填 0);刪除的項目變更數量填 0 |
| 一式項目跟著大項跑 | 「計量方式」填 `依大項百分比`,「依據分類」填分類名稱,多個用頓號分隔 |
| 哪些項目算進度 | 「計入進度」填 `是` 或 `否`(只有直接工程費填是) |
| 已開工工程的起算點 | 「起算累計」:數量項目填累計完成量;一式項目填累計百分比(60 代表 60%) |
| 工程類型 | 「工程」分頁的「工程類型」:空白=依「開口契約」欄自動判斷(一般/開口契約);新店土尾填 `土方暫置`(不產生日誌,改產生「土方月報_簡稱」);機動修繕類填 `機動修繕`(不產生日誌,回報畫面只有人員、施工項目、物料、機具、備註、照片、修繕地點) |
| 一般工程的施工地點(日誌表頭) | 「工程」分頁的「施工地點」欄 |
| 契約變更生效日 | 「工程」分頁的「第一次變更日」「第二次變更日」:那天起日誌改用變更後數量算總價與進度;沒填就一直用最新的變更數量 |
| 開口契約的日誌要不要分地點 | 「工程」分頁的「日誌方式」:空白=每個派工地點一份(日誌多一個地點下拉選單);填 `合併`=所有地點合在一張,備註欄寫地點 |
| 派工單資料 | 「派工地點」分頁:區域、工作性質、開工日、預定完工日(老闆版靠開工日判斷要不要列出這個分案) |
| 派工單的項目與數量 | 「派工數量」分頁,一列一個項目:工程(填代號或簡稱都可以)、派工地點、項次、派工數量。追加數量就再加一列,會自動加總 |
| 分案完工 | APP「設定」頁 > 派工地點(分案) > 「分案完工」(要用管理者通行碼)。會在「派工地點」分頁填上狀態「完工」和實際完工日 |
| 結算資料 | APP「設定」頁的「產生結算資料」,或試算表選單「現場回報 > 產生結算資料…」。Excel 檔存在雲端硬碟「結算資料」資料夾 |
| 派工地點結案 | 「派工地點」分頁把狀態改成 `結案`(連設定頁都不再列出) |
| 工人、機具、土質、去處 | APP 設定頁,或「設定」分頁 |

## 新店土方月報怎麼用
- 「土方月報_新店土尾」第 1 列選年、月。上半部是結存(各工地 × B5／B2-3／垃圾),下半部是當月每日進出。
- 「進」不用另外填:其他工程回報出土、去處選「新店暫置」時自動帶入。「出」是新店土尾回報出土時填,要選來源工地;B5、B2-3 運台北港,垃圾送廢清處理。

## 日誌分頁怎麼用
- 每個工程一張「日誌_簡稱」。第 1 列黃色格子是下拉選單:年度、月份(開口契約多一個派工地點),選完約 5 秒整張表會自動重算。
- 現場送出回報後,如果日誌正在顯示同一個月(同一個地點),會自動更新。要手動更新就按選單「現場回報 > 重新整理日誌」。
- 日誌是程式產生的,**不要在上面手打資料**,下次重算會被蓋掉。要修正數量請用 APP 改回報。
- 藍色區塊是要貼到施工日誌 Excel 的(第 2 列有寫範圍),貼的時候用「選擇性貼上 → 值」:
  1. 每日數量 K8:AO… → Excel「附件」K8(Google「契約-簡稱」的項目順序要跟 Excel 附件一列一列相同,含大項列)
  2. 天氣上午、下午兩列 → Excel「附件」K90
  3. 最下面的重要事項(日期～傾卸貨車)→ Excel「重要事項」這個月 1 日那一列的 A 欄

## 注意
- 回報資料分散在「每日回報、人力、出土、施工項目、機具、照片」六個分頁,用「回報編號」串起來。要改回報請用 APP 的「修改這筆回報」,不要只改其中一個分頁。
- 每次修改或刪除都會在「修改紀錄」分頁留一列。
- 照片存在公司雲端硬碟的「現場回報照片」資料夾,設定為知道連結的人可檢視。
